Overview

Concise stdout summary printed at finalize-time. Output is capped at 4 lines for a typical run (5 when duplicate / interrupted / flaky / pending counters are non-zero). Kind-less taxonomy per M6.1 decision - the in-memory Input#kind enum does not survive Storage::Snapshot persistence, so breaking down "Changed files: Templates / Locales / Ruby" would require a schema bump (deferred).

Color policy:

- Respects `NO_COLOR` per https://no-color.org/ (any value
disables, even empty string).
- Emits ANSI codes only when the output stream reports tty?.
- The header line paints red on any failure / interrupted,
yellow on pending-only, green otherwise.

  stream = output_stream
  lines.each { |line| stream.puts line }
  lines
